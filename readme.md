# YaCut — сервис укорачивания ссылок с загрузкой файлов на Яндекс.Диск

YaCut — веб-приложение, которое превращает длинные URL в короткие и управляемые ссылки. Дополнительная возможность — асинхронная загрузка нескольких файлов на Яндекс.Диск с автоматической генерацией коротких ссылок для их скачивания.

---

## 🚀 Функционал

- Создание короткой ссылки из любой длинной URL
- Возможность указания пользовательского идентификатора (custom ID)
- Автоматическая генерация уникального short ID при необходимости
- Перенаправление с короткой ссылки на оригинальную
- REST API для взаимодействия с сервисом

---

## 🛠 Технологии
- Python 3
- Flask — веб-фреймворк, приложение собрано в виде пакета
- SQLAlchemy — ORM для взаимодействия с базой данных (разработка велась на SQLite)
- aiohttp — асинхронные HTTP-запросы к API Яндекс.Диска
- Pytest — Тестирование

## 🔧 В рамках проекта выполнено: 

### Базовая функциональность:

- Создана модель URLMap с полями id, original, short, timestamp для хранения соответствия между длинными и короткими ссылками.

- Реализована главная страница с формой, где пользователь вводит длинный URL и опциональный короткий идентификатор (до 16 символов).

- Настроена валидация: проверка уникальности пользовательского идентификатора, запрет на занятие служебного пути /files, автоматическая генерация короткой ссылки из шести случайных символов (латиница + цифры) с гарантией уникальности.

- Короткие ссылки вида <short_id> выполняют редирект на исходный URL.

### Загрузка файлов на Яндекс.Диск:

- Добавлена страница /files для выбора и отправки нескольких файлов одновременно.

- С помощью библиотеки aiohttp реализована асинхронная загрузка файлов на Яндекс.Диск с параллельной обработкой.

- Для каждого загруженного файла автоматически генерируется уникальная короткая ссылка (пользовательский вариант недоступен).

- После завершения загрузки под формой динамически отображается таблица с именами файлов и готовыми короткими ссылками для скачивания.

### API:

### Реализованы два эндпоинта:

- POST /api/id/ — создание новой короткой ссылки.

- GET /api/id/<short_id>/ — получение оригинальной ссылки по короткому идентификатору.

- Ответы и ошибки соответствуют спецификации openapi.yml, включая корректные HTTP-статусы и JSON-тела.

- Обработка ошибок и интерфейс:

- Написаны кастомные обработчики ошибок для пользовательского интерфейса (страницы 404, 500) и для API (валидация, дубликат, отсутствие объекта).

- Шаблоны собраны из заготовленных макетов: базовый шаблон, главная страница, страница загрузки файлов, страницы ошибок.

- Конфигурация приложения вынесена в переменные окружения (DATABASE_URI, DISK_TOKEN), что упрощает перенос между средами.



## 🧪 Пример использования

### Создание короткой ссылки через API

```bash
POST http://localhost:5000/api/id/ 
{
    "url": "https://flask.palletsprojects.com/en/2.3.x/blueprints/"
}

```

**Ответ:**

```json
{
    "short_link": "http://127.0.0.1:5000/UGzXms",
    "url": "https://flask.palletsprojects.com/en/2.3.x/blueprints/"
}
```

## 🚀 Как запустить проект

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Активируйте виртуальное окружение (если используется):

```bash
source venv/bin/activate  # Linux/macOS
.\venv\Scripts\activate   # Windows
```

3. Создайте переменные окружения:

```bash
FLASK_APP=yacut
FLASK_DEBUG=0
DATABASE_URI='sqlite:///db.sqlite3'
FLASK_SECRET_KEY=<ваш_секретный_ключ>
``` 

4. Создайте базу данных через консоль:

```bash
>>> from yacut import db
>>> db.create_all()
```


5. Запустите приложение:

```bash
flask run
```

6. Приложение будет доступно по адресу: [http://localhost:5000](http://localhost:5000)
